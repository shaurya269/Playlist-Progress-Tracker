# Contributing

Thanks for wanting to improve Playlist Progress Tracker.

1. Fork the repo and create a branch: `git checkout -b my-change`
2. Run it locally with `npm run dev` and open http://localhost:3000
3. Keep it dependency-free: the app is plain HTML, CSS and JavaScript on purpose.
4. Run `npm run check` before you commit.
5. Open a pull request describing what changed and why.

Found a playlist that doesn't load correctly? Open an issue with the public link and the video count YouTube shows.
